# Informes de auditoría

Este directorio contiene la guía de lecciones aprendidas de las auditorías realizadas sobre el proyecto `pancheria`.

- [Lecciones aprendidas](file:///C%3A/developer/paginas/pancheria/.devin/informes/lecciones-aprendidas.md) — resumen ejecutivo de lecciones transversales para prompts y auditorías futuras.

## Cómo usar este directorio

1. Incluir `lecciones-aprendidas.md` como referencia en prompts futuros para evitar regresiones documentadas.
2. Para crear prompts nuevos, seguir la [guía de escritura de prompts](file:///C%3A/developer/paginas/pancheria/.devin/prompts/README.md).
3. Consultar <file:///C%3A/developer/paginas/pancheria/AGENTS.md> para reglas, comandos y variables de entorno del proyecto.
