# Informes de auditoría

Este directorio contiene los informes y lecciones aprendidas del proyecto `pancheria`.

- [Lecciones aprendidas](lecciones-aprendidas.md) — resumen transversal para prompts y auditorías futuras.
- [Reporte de estado — 2026-08-13](reporte-estado-2026-08-13.md) — estado actual del proyecto, verificaciones y documentación.

## Cómo usar este directorio

1. Incluir `lecciones-aprendidas.md` en prompts futuros para evitar regresiones documentadas.
2. Para crear prompts nuevos, seguir la guía de `.devin/prompts/README.md`.
3. Consultar `AGENTS.md` para reglas, comandos y variables de entorno del proyecto.
